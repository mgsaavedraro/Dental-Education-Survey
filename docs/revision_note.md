# Revision note

During peer review, the analytical workflow was audited for reproducibility. The multivariate dataset was reconstructed at participant level
so that CCI, D-OHR and TEI responses were linked within respondents. The affected multivariate analyses, tables and figure were regenerated
from the validated participant-level dataset. An additional coding discrepancy affecting four educator adoption/maintenance variables was
reconciled against the original survey responses. This repository version contains the corrected reproducible workflow; the previous
analysis is kept unchanged in `archive/previous_analysis/`.

Final analytic population: 60 students who completed the study (of 71 initial students; 84.5%) and 16 educators (76 participants).
